Catalogue add-on · AniList schedule

Anime rows that know what time it is.

Eleven catalogues built from the broadcast schedule rather than a popularity dump: what aired in the last hour, what lands today, what you are behind on. Every entry carries an IMDb or TMDB ID, which is what the anime scrapers in your plugin repositories need to find a stream.

In Nuvio: Settings → Addons → Add Addon, paste, install. Keep metadata addons above source addons in the list.

What you get

The rows are ordered by how recently something happened.

Stream sources

This addon lists anime. These repositories play it.

  1. Open Nuvio and go to Settings → Plugins.
  2. Turn on Enable local scrapers — it is off by default.
  3. Add each repository URL below with Add Repository.
  4. Enable the anime scrapers listed on each card. Names change; the chips are read live from the repositories.

Reading the repositories…

Catalogue and schedule data from AniList. ID mapping from Fribb/anime-lists. This addon supplies listings only — playback comes from your own scrapers and addons.
